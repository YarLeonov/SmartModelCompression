# SmartModelCompression
SmartModelCompression — Умное сжатие геологических моделей Разработать алгоритм интеллектуального сжатия и восстановления ансамблей геологических и гидродинамических моделей. Решение должно значительно превосходить стандартные архиваторы, сохраняя при этом возможность запуска расчетов на восстановленных моделях.
