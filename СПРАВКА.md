# Справка по решению: Сжатие геомоделей

Данное решение разработано для хакатона по сжатию гидродинамических моделей tNavigator.

## 🚀 Основной подход
Наше решение превосходит стандартное архивирование за счет двух ключевых техник:
1.  **Парсинг иерархии (INCLUDE)**: Рекурсивный поиск всех связанных файлов модели для гарантии целостности проекта.
2.  **Числовое квантование**: Обработка чисел с плавающей точкой в `.inc` файлах. Мы ограничиваем точность до 6 значащих цифр, что обеспечивает соблюдение лимита погрешности **1e-5**, при этом значительно уменьшая объем текстовых данных.

## 📂 Структура проекта
- `compress.py` — скрипт для сжатия модели в архив.
- `decompress.py` — скрипт для восстановления модели из архива.
- `submission.json` — метаданные команды для организаторов.
- `config.yaml` — настройки точности и уровней сжатия.
- `requirements.txt` — список зависимостей (используется только стандартная библиотека Python).

## 💻 Использование

### Сжатие модели
```bash
python compress.py --input <путь_к_модели> --output <имя_архива.tar.gz>
```

### Восстановление модели
```bash
python decompress.py --input <имя_архива.tar.gz> --output <путь_к_папке_восстановления>
```

## ✅ Гарантия точности
Решение протестировано на соответствие требованиям по точности (относительная погрешность не более 1e-5). Структура проекта tNavigator полностью сохраняется, что позволяет открывать восстановленную модель без дополнительных правок.
